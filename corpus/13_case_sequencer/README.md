# 13_case_sequencer

CASE-based wash sequencer: fill until high level, timed mix, drain until low level, three timed
rinse steps sharing a label range, then count the cycle. Uses a label range and ELSE.

Deliberate trap for the timer lowering: the step timer is not called while HOLD is true, yet matiec's
timers read an absolute clock, so held time still counts once the timer is called again. A lowering
that only accumulates SCAN_DT inside the call will diverge here.

Stimulus: generated by `corpus/generate_stimuli.py`.
