# 20_pump_station_supervisor

Pump station supervisor, the main demo: a two-pump station as a CASE state machine. Waits for level,
starts the lead with a proof timer, adds the lag on rising level, pumps down, then rotates the lead.
Failure to prove swaps to the other pump, and when both have failed it latches a station fault until
acknowledged. Debounced high-level alarm, flow totalizer with a pulse output in a WHILE loop, and a
FOR-based first-order level filter that runs more passes when the level moves fast.

Stimulus: generated by `corpus/generate_stimuli.py`.
